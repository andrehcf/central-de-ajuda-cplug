# Ferramentas de apoio

Scripts usados para produzir os manuais. Esta pasta não vai para o site (só `docs/` é publicada).

| Arquivo | Para que serve |
|---|---|
| `anotar-prints.ps1` | Desenha os quadrados vermelhos e as tarjas cinzas nos prints e salva em `docs/imagens/<código>/` |
| `anexar-arquivo-no-erp.js` | Anexa uma planilha ou XML num campo de upload do ERP pelo navegador interno |
| `montar-xlsx-produtos.py` | Monta a planilha de teste do 03.09 a partir do modelo do sistema (deixa só a aba Planilha1) |
| `ler-xlsx.py` | Mostra as abas e as células de um `.xlsx` sem instalar nada |

Rode os scripts Python com `python -I`, passando os arquivos baixados como argumento.
