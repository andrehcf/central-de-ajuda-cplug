# Regras para o Claude neste projeto

Antes de escrever ou revisar qualquer manual, leia e siga o **`GUIA-DOS-MANUAIS.md`** (público, tom, testar no ERP, sem linguagem de teste, estrutura, prints com tarja, revisão por agente) e o **`LEIA-ME.md`** (estrutura do projeto).

O repositório e o site são públicos: nunca coloque senha, token, dado real de cliente ou de empresa em arquivos, commits ou prints.

A cada manual novo publicado, faça SEMPRE a lista "Ao publicar um manual novo" do `LEIA-ME.md`, incluindo os três pontos da página inicial (`overrides/home.html`):

- a contagem do módulo no bloco "Já uso o sistema";
- a lista "Atualizados recentemente" (os 3 manuais mais recentes, o novo no topo);
- o passo 06 do roteiro, que vira link quando sair o manual de abrir o caixa.
